# Teado List

A simple todo list application built with Elm.

## Feature Roadmap

### Basic Features
- [ ] Filter tasks (All/Active/Completed)
- [ ] Clear completed tasks button
- [ ] Task priority levels (High/Medium/Low)
- [ ] Due dates for tasks
- [ ] Task categories/tags

### UI Enhancements
- [ ] Task sorting (by date, priority, or completion status)
- [ ] Task search functionality
- [ ] Task drag-and-drop reordering
- [ ] Task editing (double-click to edit)
- [ ] Keyboard shortcuts (Enter to add, Escape to clear input)

### Advanced Features
- [ ] Local storage persistence
- [ ] Task notes/descriptions
- [ ] Task recurrence (daily, weekly, etc.)
- [ ] Task progress tracking
- [ ] Task dependencies
